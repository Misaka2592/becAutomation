# Project workflow

For changes that follow the reviewed workflow of problem statement, proposed plan, human review, and implementation:

1. Implement the reviewed change.
2. Run the relevant validation available in the project.
3. Commit the completed change on the current branch.
4. Push the commit directly to the current branch's configured upstream remote.

Treat the human-reviewed plan as authorization to commit and push once implementation and validation are complete. Report the commit and push result, including any remote error.
